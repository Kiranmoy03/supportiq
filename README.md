# SupportIQ

**Support ticket classification with Python, scikit-learn, and Streamlit.**

[Live demo](https://supportiq-ml.streamlit.app/) · [Source code](https://github.com/Kiranmoy03/supportiq)

SupportIQ identifies the likely intent of a customer support message and suggests a next step. It uses a TF-IDF vectorizer and Logistic Regression classifier trained on labeled examples. The interface provides class scores, predefined reply templates, and a view of the model's evaluation results.

## Features

- Classifies messages into six intents: order tracking, order cancellation, refunds, payment issues, account access, and shipping address changes.
- Shows the predicted class, model score, and a suggested support action.
- Displays accuracy, macro-F1, per-class F1, a confusion matrix, and influential text features.
- Exports individual predictions as JSON.
- Keeps model training, inference, interface code, and tests in separate modules.

Response templates are predefined; they are not generated by a language model. The app does not access real orders, accounts, or payment systems.

## Model and evaluation

| Item | Details |
| --- | --- |
| Features | TF-IDF word unigrams and bigrams |
| Classifier | Multiclass Logistic Regression |
| Starter dataset | 216 manually written, illustrative tickets; 36 per intent |
| Split | Stratified 75% training / 25% test (`random_state=42`) |
| Test set | 54 examples |
| Accuracy | **83.3%** |
| Macro-F1 | **83.1%** |

These are held-out results on the small **synthetic starter dataset**, not an evaluation of real-world customer requests. Model scores are not calibrated probabilities. The trained model supplied in `artifacts/` is refit on the full starter dataset after evaluation.

For a closer look at individual categories, open **Model insights** in the live app.

## Run locally

Python 3.12 is recommended.

```bash
git clone https://github.com/Kiranmoy03/supportiq.git
cd supportiq
python -m venv .venv
```

Activate the virtual environment:

- Windows PowerShell: `.venv\Scripts\Activate.ps1`
- macOS/Linux: `source .venv/bin/activate`

Then install dependencies and launch the app:

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

The application uses the saved model in `artifacts/intent_classifier.joblib` and evaluation results in `artifacts/metrics.json`. No API keys or database setup are required.

## Train the model

Train again on the included starter dataset:

```bash
python -m scripts.train --source demo
```

The project also supports retraining on the public [Bitext customer-support dataset](https://huggingface.co/datasets/bitext/Bitext-customer-support-llm-chatbot-training-dataset):

```bash
python -m scripts.train --source bitext
```

That command downloads the dataset and selects examples from the six intents used by SupportIQ; it **does not train on all 26,872 rows**. Bitext is synthetic/hybrid-generated data, licensed under CDLA-Sharing-1.0 and credited to Bitext Innovations. The external dataset is not bundled with this repository. Review the [dataset license](https://github.com/bitext/customer-support-llm-chatbot-training-dataset/blob/main/LICENSE.txt) before redistributing it.

The training code validates labels, removes duplicate requests, splits data before training, evaluates held-out examples, and saves a final classifier trained on all eligible examples. If retraining, commit the new model and metrics artifacts to deploy them.

## Deployment

The live version runs on [Streamlit Community Cloud](https://supportiq-ml.streamlit.app/) from `main`, with `app.py` as the entry point. The cloud build installs dependencies from `requirements.txt`.

## Limitations

This project demonstrates text classification, not automated customer support. It will sometimes misclassify unfamiliar, ambiguous, or multi-intent messages. Accuracy measured on a small synthetic dataset may not reflect real-world performance. Human review and more varied training data would be needed for a production setting.

Do not enter passwords, card numbers, or sensitive personal details into the public demo. Load only trusted `joblib` model files, since they use Python's pickle-based serialization.
